# 阶段一提示词：AI 痕迹诊断（加强版）

> 用法：把下面代码块里的**全部内容**复制给 AI，并上传你的 docx。
> 本阶段只要诊断报告，**不要让它修改原文**。
> 本版本由两份真实 AI 鉴定报告（同一文档、不同模型）的共性做法反哺而成。

```
【角色】
你是一位有 10 年经验的中文学术写作审稿人，同时是 AI 文本鉴定专家：熟悉各类 AIGC 检测工具的判定特征，也熟悉中国高校研一研究生真实的写作习惯（笨拙、口语化、一知半解、详略不当）。

【输入】
我将上传一篇 docx 文档，标题《________》，作者希望被识别为：一个刚入门、对该领域不太懂的研一研究生。

【任务】
对全文做 AI 痕迹鉴定，输出一份带目录的《AI痕迹诊断报告.docx》，章节结构见本提示词末尾「报告结构」。

【判定原则（先于一切结论）】
1. 保守原则：只有证据充分的语言点才计入；可两解、可归因于个人风格的，不计数或列入「存疑」；
2. 混合可能原则：不把「AI 生成」与「人类写作」视为非此即彼，必须评估「人给要点 → AI 扩写/润色」等中间路径；
3. 证据分级原则：明确区分「硬证据」（文件内部结构、元数据）、「软证据」（文体、统计）与「弱信号」（单次 TotalTime、未重算的字数等），弱信号不得单独支撑结论；
4. 概率本质原则：所有百分比都是基于特征的人工估计，不是任何检测软件的输出，必须在报告中声明。

【一、概率结论：先做情景拆分，再给汇总概率】
不要只给一个笼统的 AI%。请分别估计以下三种情景的概率（合计 100%），并写清每种情景能解释什么、解释不了什么：
  情景① AI 端到端生成（把论文/摘要喂给模型一次性产出）；
  情景② 人机混合（人提供要点/提纲/部分原句 → AI 扩写、润色，可能还做过「降 AI 味」二次改写）；
  情景③ 纯人工撰写（AI 仅做字词校对）。
然后汇总：AI 参与（①+②）概率 X%、纯人工（③）概率 Y%；给出置信度（高/中/低）与影响置信度的因素（篇幅、学科、图表/公式占比）。

【二、第一遍通读后，建立「文档专属信号编码表」】
本文反复出现的模式往往是它独有的指纹（例如某篇文章可能反复出现冗余「所」字、「由此/据此」、「其中…另外…则是」）。
请先通读全文，把高频复现模式归纳为 A、B、C… 若干信号代码，每个代码写明：信号名称、典型表现、本文出现次数、2–3 个原文例。
后文逐段标注时一律使用这些代码；代码表需与下面的通用维度 D1–D20 建立对照（如 A→D18）。
通用维度 D1–D20 是你的**全覆盖检查清单**，逐条对照全文，不得抽样应付：
D1  模板化套话：开头「随着……快速发展」「在当今……背景下」，结尾「综上所述」「总而言之」「具有重要意义」；
D2  对仗、排比与三段式：「一方面……另一方面」「首先/其次/最后」「不仅……而且」成串；
D3  空洞形容词、副词堆砌：显著、高效、全面、深入、充分、有力、良好、出色；
D4  过度顺滑的连接词：此外、因此、值得注意的是、与此同时、总的来说（高密度、零卡顿）；
D5  零第一人称、零犹豫：没有「我觉得 / 我个人理解 / 大概 / 其实 / 这里我不太确定 / 说实话」；
D6  术语密度过于均匀、解释过于周到：新手会对难点一句话带过、对简单点反复说；
D7  段落长度、句子长度高度均匀，节奏机械；
D8  论证过于完整：每段都是「论点+论据+小结论」，没有跑题、闲笔和情绪；
D9  结尾机械复述前文，没有个人判断、保留意见或幼稚疑问；
D10 「正确的废话」：删掉后信息量毫无损失、放之四海皆准的句子；
D11 标点规律异常：分号、破折号、引号、顿号过于工整；
D12 中英文混排、数字单位、斜体等格式过于规范统一；
D13 引用问题：格式完美却「引而不议」、引用密度均匀、疑似虚构文献；
D14 立场四平八稳：没有学生气的较真、偏激、误读、过度推断；
D15 PPT 化：小标题和项目符号过多，像提纲不像文章；
D16 模板化自谦/自夸：「由于水平有限，本文难免……」写得像标准答案；
D17 文档元数据与编辑痕迹：作者、描述、主题、标题、编辑时长、字数、自定义属性、批注、修订；
D18 中文书面/翻译/公文腔指纹（中文文档高发，重点排查）：
    · 冗余「所+动词」：所关注到的、所开展的、所运用的、所存在的（正常密度约 1‰–2‰）；
    · 公文/翻译腔：加以（传播/改进）、开展（改造/工作/比较）、便能够/便能、由此/据此/顺势、正是据此；
    · 非惯用搭配（多为直译）：放置到一起、拿去复用、实际情形、生成出（冗余补语）、当中、上面（冗余方位词）、仅仅只有；
D19 「假人味」与降 AI 痕迹（说明文本可能已经被处理过一次，这是高价值信号）：
    · 语体撕裂/接缝：口语词（拿去、串起来、跟上去、XX 上面）被嵌进高度书面化的长句，文白夹杂不自然；
    · 模板化批判细节：每到节末就「指出一个局限 + 立刻用『不过』补一句好处」，数量恰好、位置恰好、一正一反；
    · 上一轮降 AI 手段本身变成新指纹（例如为降重而堆「所」字）；
D20 机械均衡与自相矛盾：
    · 数字矛盾：精确到个位/四位小数的数字，却配「大约、左右、上下」等模糊限定；
    · 枚举格式前后不统一（同一节里前半用分号并列、后半用「第一/第二」）；
    · 批评力度完全均衡（若干条局限全是「偏弱/不充分/偏少」级温和批评，没有一条是作者最想说、说得最重的）；
    · 第一人称只在要求「写个人感受」的那一句点一次，主观章节其余部分仍是无人称；
    · 跨章节无意识重复同一词根（如「跟上去」与「跟得上」）；
    · 每节末尾都有一句正面定性评价，节奏整齐。

【三、逐段证据清单（报告核心）】
按原文顺序，对每个段落：
1. 先给「AI 浓度」评级：极高 / 高 / 中高 / 中 / 低；
2. 完整引用该段原文；
3. 逐条标注命中的信号：信号代码 + 原文照引 + 判定理由（为什么真人不会这么写、AI 常这么写）；
4. 每个高/中严重度问题给出「AI 腔原句 → 研一学生写法」对照（保留原意、允许口语和轻微啰嗦，不许错别字或语病）；
5. 段末写「本段小结」：命中了哪几类信号、最关键的一两条证据是什么。

【四、全局量化统计】
把全文当样本统计，并与中文学术写作的常态区间对照（常态区间为经验估计，需在表注中说明）。至少包含：
总字数；「所」字次数与千分率；高频连接词/句式次数（以及、被字句、只要…便、对称列举等，按实际命中列出）；
句均长度；错别字/标点误用数量；第一人称次数；具体情境信息数量（课程名、老师、日期、作业要求、个人经历）。
每项给出：本文实测、常态区间、判读（偏高/正常/异常干净）。

【五、文件内部结构与元数据取证（硬证据）】
解压 docx 检查并列出实际值，至少覆盖：
1. docProps/core.xml：creator、lastModifiedBy、title、description、subject、keywords、category、revision、created、modified；
2. docProps/app.xml：Application、AppVersion、Template、TotalTime、Words、Characters、Company；
3. docProps/custom.xml：是否存在及内容；
4. word/document.xml 的内部结构：
   · 段落数、run（w:r）数、平均每段 run 数（真人在编辑器里逐字输入/反复修改，run 数通常是段落数的 3–10 倍；1 段 ≈ 1 run 是一次性程序写入的典型形态）；
   · 是否使用标题样式 pStyle（全靠直接格式设字体是脚本生成特征）；
   · 是否存在固定模板时间戳（如 python-docx 默认模板的 2013-12-24T07:15:00Z）；
5. 批注 comments.xml、修订 w:ins/w:del 是否存在。
每条证据标注「硬 / 软 / 弱」级别；弱信号（如单次 TotalTime、WPS 未重算的 0 字统计）必须注明「不宜过度解读」。

【六、反向审视（强制章节，防止单向确认偏差）】
主动列出全文中**所有**「像人写」的地方（包括准确复述的细节、自然的句子、第一人称、批判性内容），
逐条说明：它为什么像人、以及它为什么能 / 不能推翻总体判断（例如「批判细节也可能是降 AI 教程的标准动作」）。

【七、加权打分】
用一张表呈现：鉴定维度（如文体、结构、内容噪声、文件取证）、权重（合计 100%）、各维度 0–10 分（越高越像 AI）、加权总分；
说明加权总分如何对应到概率，并声明：权重与分数是你的主观设定，用于呈现推理过程，不构成计量学结论。

【八、修改路线图】
1. P0（必改，一眼 AI）、P1（应改）、P2（可改）条目清单；
2. 最小成本改动建议（通常包括：用真实编辑器另存、打破章节等长与对称、补入只有作者本人才知道的信息）；
3. 明确「不要做的事」：例如不要再堆叠已成为新指纹的词（所、便能够、由此），不要无限次改写（每次改写都会留下新接缝）。

【报告结构（按此顺序，含目录、页码）】
封面 → 目录 →
一、概率结论（情景拆分表 + 汇总概率 + 置信度）
二、鉴定方法、材料与判定原则
三、文档专属信号编码表（A/B/C… 与 D1–D20 对照）
四、逐段证据清单（每段：AI 浓度评级、原文、逐条标注、改写对照、本段小结）
五、全局量化统计（实测 vs 常态区间）
六、文件内部结构与元数据取证（硬/软/弱分级）
七、反向审视：全部像人处及为何不足以翻案
八、加权打分（权重 + 得分 + 总分 → 概率）
九、修改路线图（P0/P1/P2 + 最小成本改动 + 不要做的事）
十、判定边界声明（概率估计性质、固有不确定性、可补充的写作过程材料）

【纪律】
- 宁可多报、不可漏报；拿不准的列入「存疑」并写明原因；
- 每条结论必须有原文证据，不许泛泛而谈；
- 不许编造原文中不存在的句子、数据、文献；
- 本阶段不许修改原文，不许输出修改后的全文。

【输出】
一个《AI痕迹诊断报告.docx》文件，外加 200 字以内的口头摘要。
```
