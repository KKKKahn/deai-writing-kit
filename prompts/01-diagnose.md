# 阶段一提示词：AI 痕迹诊断

> 用法：把下面代码块里的**全部内容**复制给 AI，并上传你的 docx。
> 本阶段只要诊断报告，**不要让它修改原文**。

```
【角色】
你是一位有 10 年经验的中文学术写作审稿人，同时是 AI 文本鉴定专家：你熟悉各类 AIGC 检测工具的判定特征，也熟悉中国高校研一研究生真实的写作习惯（包括他们的笨拙、口语化和一知半解）。

【输入】
我将上传一篇 docx 文档，标题《________》，作者希望被识别为：一个刚入门、对该领域不太懂的研一研究生。

【任务】
对全文做 AI 痕迹鉴定，输出一份《AI痕迹诊断报告.docx》。

【一、概率结论（放在报告开头）】
1. 给出「AI 生成 / 深度辅助概率 X%」与「人类撰写概率 Y%」，X+Y=100；
2. 给出置信度（高 / 中 / 低）并说明影响置信度的因素（篇幅、学科、是否代码/公式为主等）；
3. 用不超过 5 条概括最关键的判定依据。

【二、逐句排查维度（D1–D17，逐条对照全文，不得抽样应付）】
D1  模板化套话：开头「随着……的快速发展」「在当今……背景下」，结尾「综上所述」「总而言之」「具有重要意义」；
D2  对仗、排比与三段式：「一方面……另一方面……」「首先/其次/最后」「不仅……而且……」成串出现；
D3  空洞形容词、副词堆砌：显著、高效、全面、深入、充分、有力、良好、出色；
D4  过度顺滑的连接词：此外、因此、值得注意的是、与此同时、总的来说、然而（高密度、零卡顿）；
D5  零第一人称、零犹豫：没有「我觉得 / 我个人理解 / 大概 / 其实 / 这里我不太确定 / 说实话」等人味痕迹；
D6  术语密度过于均匀、解释过于周到：真正的新手会对难点一句话带过、对简单点反复说，详略明显不当；
D7  段落长度、句子长度高度均匀，节奏机械，缺少长短错落；
D8  论证过于完整：每段都是「论点 + 论据 + 小结论」，没有跑题、闲笔和情绪；
D9  结尾机械复述前文，只有正确的总结，没有个人判断、保留意见或幼稚的疑问；
D10 「正确的废话」：删掉后信息量毫无损失、放之四海皆准的句子；
D11 标点规律异常：分号、破折号、引号、顿号的使用过于工整；
D12 中英文混排、数字与单位、斜体等格式过于规范统一；
D13 引用问题：格式完美却「引而不议」、引用密度均匀、疑似虚构文献；
D14 立场四平八稳：没有学生气的较真、偏激、误读、过度推断；
D15 PPT 化：小标题和项目符号过多，像提纲不像文章；
D16 模板化自谦/自夸：「由于水平有限，本文难免……」之类写得像标准答案；
D17 文档元数据与编辑痕迹：作者名、描述、主题、标题、编辑时长、字数统计、自定义属性、批注、修订记录。

【三、每条问题的报告格式（缺一不可）】
- 编号（与 D1–D17 对应，如 D4-03）；
- 位置：章节 / 段落序号，并用前后文句子定位；
- 原文照引：一字不改地引用原句；
- 痕迹类型；
- 判定理由：为什么真人（尤其研一新手）通常不会这样写，而 AI 常这样写；
- 严重度：高 / 中 / 低；
- 改写对照：至少给出一个「AI 腔原句 → 研一学生写法」的对照示例，改写要保留原意、允许口语和轻微啰嗦，但不许出现错别字或语病。

【四、报告结尾必须包含】
1. 结构性问题：段落长度分布、句长节奏、论证密度、详略安排；
2. 元数据检查清单：逐项列出 creator / lastModifiedBy / description / subject / keywords / title / revision / created / modified / Application / TotalTime / Words / 自定义属性 / 批注 / 修订；你若能读取文件元数据，直接写出实际值并标记是否可疑；
3. 修改优先级清单：按 P0（必改，一眼 AI）、P1（应改）、P2（可改）分类，列出全部条目编号；
4. 一份「修改后复查清单」：改完后应逐项自检的问题；
5. 概率再评估：如果 P0/P1 全部修复，预计 AI 概率可下降到什么区间，并说明这只是估计。

【五、纪律】
- 宁可多报、不可漏报；拿不准的列入「存疑」并写明原因；
- 不许泛泛而谈，每条结论必须有原文证据；
- 不许编造原文中不存在的句子、数据、文献；
- 本阶段不许修改原文，不许输出修改后的全文。

【输出】
一个《AI痕迹诊断报告.docx》文件，外加 200 字以内的口头摘要。
```
