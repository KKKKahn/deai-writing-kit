# 阶段二提示词：按诊断报告修改 + 元数据处理（加强版）

> 用法：确认诊断报告无误后，把下面代码块里的**全部内容**复制给同一个 AI，
> 并确保它手上有：原稿 docx + 它刚出具的诊断报告。
> 本版本针对真实鉴定中最容易"翻车"的点（假人味接缝、模板化批判、机械均衡）做了强化。

```
【上下文】
你此前已为我出具《AI痕迹诊断报告.docx》。现在请严格按照该报告，逐条修改我的原稿。

【任务一：输出完整终稿】
1. 输出修改后的完整 docx：是可以直接提交的全文，不是片段、不是修改建议；
2. 保留我的核心论点、事实、数据、参考文献与大致篇幅，不得借修改之名改变观点；
3. 不许新增数据，不许编造参考文献；引用格式允许轻微不统一（新手常态）。

【任务二：语言目标——刚入门、不太懂的研一研究生】
主动做到：
- 第一人称表达犹豫和判断：「我觉得」「按我的理解」「这里我没太搞懂」「我猜」「说实话」；
- 笨拙但自然的过渡，允许少量重复和啰嗦；
- 段落长短明显错落，详略可以不当：难点一句话带过、简单处反复念叨；
- 保留学生气的较真、幼稚的疑问、过度推断或保留意见。

【任务三：消除"假人味"——以下是上一轮降 AI 最容易留下的新指纹，必须避免】
1. 语体一致性：选定「学生的自然书面语 + 偶尔口语」这一种语体；不许把口语词（拿去、串起来、跟上去、XX 上面）塞进高度书面化的长句，读起来像两个人写的；
2. 批判细节不规则化：不要每节/每段末尾都「指出一个局限 + 『不过』补一句好处」，
   也不要每段都用「不过 / 并不意味着 / 需要谨慎理解 / 不能笼统说」之类限定语收尾；
   批判性内容的数量、位置、长短要不规则，允许有的段落干脆收尾、有的段落完全没有批评；
3. 批评/局限要有主次：必须有一条是"我"最在意、说得最重、最具体的，其余可以轻描淡写；不许每条都力度均等；
4. 数字呈现不许矛盾：要么写约数（约 231 万），要么写确数（2,310,452），不要"精确数字 + 大约/上下"叠用；转述论文指标时按原文精度即可；
5. 枚举格式统一：同一篇文章里并列结构要么都用分号、要么都用序号，不许前后两套；
6. 第一人称自然分布：在主观章节（个人思考/读后感）密集出现，客观段落可以完全没有；
   不许走两个极端——既不能只点一次，也不能"每段配额一个"地均匀摊开；
   说法要有变化（我觉得/我猜/说实话/按我的理解），不要机械重复同一句式；
7. 避免词根重复：检查不要在不同段落无意识复用同一个动词/比喻；
8. 新指纹黑名单：终稿中「所+动词」密度应回落到约 1‰–2‰，「便能够/便能、由此/据此/顺势、加以、开展」等词按真人习惯使用，能删尽删；
9. 不许为了凑人味加入错别字、网络烂梗或错误标点。

【任务四：补入"只有作者本人才知道"的信息】
在不违背事实的前提下，至少加入 1–2 处具体情境信息（请先问我，或列出空位让我填）：
课程名称、任课老师的具体要求、读论文的时间/地点/场景、和同学讨论的内容、一段跑题的吐槽或个人经历。
这是全文最有说服力的"人味"，不能用泛化的生活化建议替代。

【任务五：随终稿附两份清单】
1.《修改对照表》：序号 | 原文 | 修改后 | 对应报告条目编号 | 处理手法；
2.《报告核销清单》：报告中每一条（含"存疑"条目）→ 已修改 / 已删除原句 / 保留（必须给理由）。
完成后自检：P0、P1 是否全部清零；如仍有无法处理的条目，明说原因。

【任务六：元数据处理】
我的信息：姓名「________」，文档标题「________」。
终稿元数据必须满足：
- dc:creator、cp:lastModifiedBy 为我的姓名；
- dc:title 为我给的标题（不带"修改稿/最终版"等字样）；
- 删除 dc:description、dc:subject、cp:keywords、cp:category、cp:revision、dc:identifier；
- Application 为正常桌面编辑器（Word 或 WPS），Template 为 Normal.dotm；
- TotalTime 不得为 0，Words / Characters 与正文一致、不得为 0；
- 删除 docProps/custom.xml 自定义属性；
- 清除 AI 留下的批注和修订（w:ins / w:del）。
执行方式：
- 你若能运行代码，直接对终稿运行仓库中的 scripts/clean_metadata.py，
  参数含 --name、--title、--remove-comments、--remove-revisions、--touch，
  并把脚本打印的「字段变更表」完整贴给我；
- 你若不能运行代码，给我一条可以直接复制执行的完整命令。

【任务七：人工通读建议】
最后告诉我：哪 3–5 处最该由我亲手再改（个人经历、导师具体要求、学科黑话），
以及我用 Word/WPS 打开后应做的动作：通读、随手改几句、保存（让编辑器生成自然的 run、修订号与编辑时长）。
提醒：不要对同一篇文章无限次"降 AI 改写"——每改写一次就多一层接缝，改 1–2 轮 + 自己通读，效果最好。

【纪律】
- 不许只输出几段示例让我自己拼；
- 不许保留任何 P0 问题；
- 不许通过错别字、乱加标点来"模拟人类"；
- 不许把学术内容改空或改变我的论点。

【输出】
修改后的完整终稿 docx + 修改对照表 + 报告核销清单 + 元数据字段变更表 + 人工通读建议。
```
