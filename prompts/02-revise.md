# 阶段二提示词：按诊断报告修改 + 元数据处理

> 用法：确认诊断报告无误后，把下面代码块里的**全部内容**复制给同一个 AI，
> 并确保它手上有：原稿 docx + 它刚出具的诊断报告。

```
【上下文】
你此前已为我出具《AI痕迹诊断报告.docx》。现在请严格按照该报告，逐条修改我的原稿。

【任务一：输出完整终稿】
1. 输出修改后的完整 docx：是可以直接提交的全文，不是片段、不是修改建议；
2. 保留我的核心论点、事实、数据、参考文献与大致篇幅，不得借修改之名改变我的观点；
3. 不许新增数据，不许编造参考文献；引用格式允许轻微不统一（这是新手常态）。

【任务二：语言目标——刚入门、不太懂的研一研究生】
主动做到：
- 用第一人称表达犹豫和判断：「我觉得」「按我的理解」「这里我没太搞懂」「我猜」「说实话」；
- 笨拙但自然的过渡，允许少量重复和啰嗦；
- 段落长短明显错落，详略可以不当：难点一句话带过、简单处反复念叨；
- 保留一点学生气的较真、幼稚的疑问、过度推断或保留意见；
- 报告中的 P0、P1 条目必须全部清零，P2 条目逐条说明处理结果；
- 彻底清除 D1–D16 类痕迹（模板套话、对仗排比、空洞形容词、机械连接词、正确的废话等）。
但不许：出现错别字、明显语病、网络烂梗；不许把学术内容改空。

【任务三：随终稿附两份清单】
1.《修改对照表》：序号 | 原文 | 修改后 | 对应报告条目编号 | 处理手法；
2.《报告核销清单》：报告中每一条（含"存疑"条目）→ 已修改 / 已删除原句 / 保留（必须给理由）。

【任务四：元数据处理】
我的信息：姓名「________」，文档标题「________」。
终稿的元数据必须满足：
- dc:creator、cp:lastModifiedBy 为我的姓名；
- dc:title 为我给的标题（不得带"修改稿/最终版"等字样）；
- 删除 dc:description、dc:subject、cp:keywords、cp:category、cp:revision、dc:identifier；
- Application 为正常桌面编辑器（Word 或 WPS），Template 为 Normal.dotm；
- TotalTime 不得为 0，Words / Characters 必须与正文一致、不得为 0；
- 删除 docProps/custom.xml 自定义属性；
- 清除 AI 留下的批注和修订（w:ins / w:del）。
执行方式：
- 你若能运行代码，直接对终稿运行仓库中的 scripts/clean_metadata.py，
  参数含 --name、--title、--remove-comments、--remove-revisions，
  并把脚本打印的「字段变更表」完整贴给我；
- 你若不能运行代码，给我一条可以直接复制执行的完整命令。

【任务五：人工通读建议】
最后告诉我：哪 3–5 处最该由我亲手再改（比如涉及我个人经历、导师具体要求、学科黑话的地方），
以及我用 Word/WPS 打开后应做哪些动作（通读、随手改句、保存）。

【纪律】
- 不许只输出几段示例让我自己拼；
- 不许保留任何 P0 问题；如确有无法处理的条目，明说原因；
- 不许通过错别字、乱加标点来"模拟人类"。

【输出】
修改后的完整终稿 docx + 修改对照表 + 报告核销清单 + 元数据字段变更表 + 人工通读建议。
```
